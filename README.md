# IAW · UD3 · Ejercicios de Python (Bloques 1 y 2)

Ejercicios del módulo **Implantación de Aplicaciones Web** (2º ASIR), unidad *UD3: Python introduction*.

## Cómo está organizado el repositorio

- `main` contiene este README y el [manual de supervivencia de Python](https://github.com/Wafo00/IAW/blob/main/manual-python-supervivencia.md): cada ejercicio vive en su propia rama.
- Una rama por ejercicio, `ejercicio_N`, con un único fichero `ejercicio_N.py`.
- **Bloque 1**: ejercicios **1-10** obligatorios y **11-20** opcionales, todos resueltos.
- **Bloque 2**: ejercicios **21-30** obligatorios y **31-40** opcionales, todos resueltos.
- Para probar cualquiera: abrir la rama, descargar el `.py` y ejecutarlo con `py ejercicio_N.py` (Windows) o `python3 ejercicio_N.py` (Linux/macOS).

## Criterios seguidos

- Solo se ha usado lo visto hasta ahora en clase. En el Bloque 1: entrada/salida, tipos numéricos, operadores aritméticos (incluidos `//` y `%`), f-strings y secuencias básicas. En el Bloque 2 se añaden condicionales (`if/elif/else`), bucles (`for`, `while`), banderas booleanas, bucles anidados y los módulos `random` y `time`.
- Nombres de variable según lo que contienen (`peso_parciales`, `total_empresa`, `primos_mostrados`...).
- Los valores fijos del enunciado van en variables con nombre (`comision`, `acierto`, `pausa`...), no escritos sueltos dentro de las fórmulas.
- Cada programa se ha probado con datos "no bonitos" (evitando ceros y redondos, que esconden errores) y comparando con el cálculo hecho a mano.
- Donde el enunciado deja algo sin definir, la suposición queda escrita en un comentario del propio fichero.
- Las mejoras posteriores se suben como commits nuevos sobre la misma rama, de modo que el historial muestra el antes y el después.

## Evolución

Los ejercicios del Bloque 1 se hicieron antes de ver condicionales y bucles. Cuando avance el temario (funciones, excepciones, etc.) se irán revisando y mejorando algunos de ellos, siempre como commits nuevos sobre cada rama.
