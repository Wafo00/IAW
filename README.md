## Criterios seguidos

- Solo se ha usado lo visto hasta 23/10/2026 en clase: entrada/salida, tipos numéricos, operadores aritméticos (incluidos `//` y `%`), f-strings y secuencias básicas.
- Nombres de variable según lo que contienen (`peso_parciales`, `aporte_*`, `valor_*`, `mon_*`...).
- Los valores fijos del enunciado van en variables con nombre (`comision`, `acierto`, `fallo`...), no escritos sueltos dentro de las fórmulas.
- Cada programa se ha probado con datos "no bonitos", evitando ceros y redondos, y comparando con el cálculo hecho a mano.
- Donde el enunciado deja algo sin definir, la suposición queda escrita en un comentario del propio fichero.
